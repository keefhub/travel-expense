# Feature 3: Create New Trip

```gherkin
Feature: Create new trip
  As a traveller
  I want to create a new trip
  So that I can start tracking expenses for a different journey

  Scenario: User starts creating a new trip while another trip exists
    Given the user already has an active trip
    When the user chooses to create a new trip
    Then the app should warn the user that the current trip and its related data will be deleted
    And the app should ask the user to confirm before continuing

  Scenario: User confirms new trip creation
    Given the user has confirmed that they want to create a new trip
    When the user completes the new trip setup
    Then the app should delete the previous trip data from local storage
    And the app should save the new trip data in local storage
    And the app should redirect the user to the home dashboard

  Scenario: User cancels new trip creation
    Given the user is shown the new trip confirmation warning
    When the user cancels the action
    Then the existing trip data should remain unchanged
```
