# Feature 7: Exchange Rate Management

```gherkin
Feature: Exchange rate management
  As a traveller
  I want to enter fixed exchange rates
  So that the app can convert foreign currency expenses into my trip currency

  Scenario: User views exchange rate settings
    Given the user has an active trip
    When the user opens exchange rate settings
    Then the app should show the trip currency
    And the app should show currencies used by recorded expenses that are different from the trip currency

  Scenario: User adds an exchange rate
    Given the user has recorded expenses in a non-trip currency
    When the user enters a valid exchange rate from that currency to the trip currency
    And the user saves the exchange rate
    Then the exchange rate should be saved in local storage
    And the dashboard should update converted totals

  Scenario: User updates an exchange rate
    Given an exchange rate already exists
    When the user changes the exchange rate value
    And the user saves the change
    Then the updated exchange rate should be saved in local storage
    And converted totals should be recalculated

  Scenario: User enters an invalid exchange rate
    Given the user is editing exchange rates
    When the user enters zero, a negative number, or a non-numeric exchange rate
    Then the app should show a validation message
    And the exchange rate should not be saved
```
