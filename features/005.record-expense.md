# Feature 5: Record Expense

```gherkin
Feature: Record expense
  As a traveller
  I want to record expenses during my trip
  So that I can track what I spend

  Scenario: User opens the record expense page
    Given the user has an active trip
    When the user navigates to the record expense page
    Then the app should display the expense form
    And the form should include amount
    And the form should include currency
    And the form should include category
    And the form should include expense date
    And the form should include payment method
    And the form should include location
    And the form should include optional description

  Scenario: Expense date defaults to today
    Given the user opens the record expense page
    When the expense form is displayed
    Then the expense date should default to today's date

  Scenario: User records a valid expense
    Given the user is on the record expense page
    When the user enters a valid amount
    And the user selects a currency
    And the user selects a category
    And the user selects an expense date
    And the user selects or enters a payment method
    And the user enters a location
    And the user optionally enters a description
    And the user saves the expense
    Then the expense should be saved in local storage
    And the app should show a success message
    And the user should be redirected to the home dashboard

  Scenario: User records a future-dated expense
    Given the user is on the record expense page
    When the user enters a future date for the expense
    And all mandatory fields are valid
    Then the app should allow the expense to be saved

  Scenario: User records an expense outside the trip period
    Given the user is on the record expense page
    When the user enters an expense date outside the trip start and end dates
    Then the app should show a warning that the expense date is outside the trip period
    And the user should still be allowed to save the expense

  Scenario: User submits expense with missing mandatory fields
    Given the user is on the record expense page
    When the user submits the form without amount, currency, category, date, payment method, or location
    Then the app should show validation messages
    And the expense should not be saved

  Scenario: User submits invalid amount
    Given the user is on the record expense page
    When the user enters zero, a negative number, or a non-numeric amount
    Then the app should show a validation message
    And the expense should not be saved
```
