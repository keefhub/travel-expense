# Feature 1: First-Time Travel Setup

```gherkin
Feature: First-time travel setup
  As a traveller
  I want to set up my trip when I first use the app
  So that the app can track expenses against the correct country, travel period, currency, and budget

  Scenario: First-time user opens the app
    Given the user has no active trip saved in local storage
    When the user opens the app
    Then the app should display the travel setup screen
    And the app should ask the user to select a destination country
    And the app should ask the user to enter a start date
    And the app should ask the user to enter an end date
    And the app should allow the user to enter an optional trip budget

  Scenario: User completes travel setup successfully
    Given the user is on the travel setup screen
    When the user selects a supported destination country
    And the user enters a valid start date
    And the user enters a valid end date
    And the user optionally enters a valid trip budget
    And the user submits the setup form
    Then the app should calculate the trip duration in days
    And the app should map the destination country to the expected trip currency
    And the app should save the trip details in local storage
    And the user should be redirected to the home dashboard

  Scenario: User skips optional budget
    Given the user is on the travel setup screen
    When the user selects a supported destination country
    And the user enters a valid start date
    And the user enters a valid end date
    And the user does not enter a trip budget
    And the user submits the setup form
    Then the app should save the trip without a budget
    And the dashboard should not show remaining budget calculations

  Scenario: User enters an invalid travel period
    Given the user is on the travel setup screen
    When the user enters an end date earlier than the start date
    Then the app should show a validation message
    And the app should not save the trip setup

  Scenario: User enters an invalid budget
    Given the user is on the travel setup screen
    When the user enters a zero, negative, or non-numeric budget
    Then the app should show a validation message
    And the app should not save the trip setup

  Scenario: Returning user opens the app
    Given the user has an active trip saved in local storage
    When the user opens the app
    Then the app should skip the travel setup screen
    And the user should see the home dashboard
```
