# Feature 10: Manage Expense Categories

```gherkin
Feature: Manage expense categories
  As a traveller
  I want to manage custom expense categories
  So that I can organise expenses in a way that fits my trip

  Scenario: User views default categories
    Given the user is on the record expense page
    When the category field is displayed
    Then the app should show default categories
    And the default categories should include Food, Transport, Accommodation, Shopping, Activities, and Others

  Scenario: User adds a custom category
    Given the user is managing categories
    When the user enters a new unique category name
    Then the custom category should be saved in local storage
    And the category should be available for future expenses

  Scenario: User cannot add duplicate category
    Given the user is managing categories
    When the user enters a category name that already exists
    Then the app should show a validation message
    And the duplicate category should not be saved

  Scenario: User renames a custom category
    Given the user has created a custom category
    When the user renames the custom category
    Then the new category name should be saved in local storage
    And existing expenses using the old category name should be updated to the new category name

  Scenario: User deletes a custom category used by existing expenses
    Given the user has created a custom category
    And one or more expenses are using that custom category
    When the user deletes the custom category
    Then the category should be removed from future category selection
    And existing expenses should keep the deleted category name

  Scenario: User deletes a custom category not used by existing expenses
    Given the user has created a custom category
    And no expenses are using that custom category
    When the user deletes the custom category
    Then the category should be removed from local storage
    And the category should no longer be available for future expenses

  Scenario: User cannot rename or delete default categories
    Given the category is a default category
    When the user views category management actions
    Then rename and delete actions should not be available for that default category
```
