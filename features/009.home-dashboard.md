# Feature 9: Home Dashboard

```gherkin
Feature: Home dashboard
  As a traveller
  I want to see a summary of my travel spending
  So that I can understand my expenses at a glance

  Scenario: User views dashboard with no expenses
    Given the user has created an active trip
    And no expenses have been recorded
    When the user views the dashboard
    Then the app should show the destination country
    And the app should show the travel dates
    And the app should show the number of travel days
    And the app should show the trip currency
    And the app should show a zero spending summary
    And the app should show an empty state for recent transactions

  Scenario: User views total spending
    Given the user has recorded expenses
    When the user views the dashboard
    Then the app should show total spending
    And the totals should be displayed using currency codes

  Scenario: User views spending by category
    Given the user has recorded expenses across categories
    When the user views the dashboard
    Then the app should show a pie chart of spending by category

  Scenario: User views last five transactions
    Given the user has recorded more than five expenses
    When the user views the dashboard
    Then the app should show the latest five transactions
    And the transactions should be sorted by expense date from newest to oldest

  Scenario: User views fewer than five transactions
    Given the user has recorded fewer than five expenses
    When the user views the dashboard
    Then the app should show all recorded transactions
    And the transactions should be sorted by expense date from newest to oldest

  Scenario: User views recent transaction details
    Given the user is viewing the last five transactions
    When the user taps or clicks a transaction
    Then the app should show the transaction details
    And the details should include date, category, currency, amount, payment method, location, and description if available

  Scenario: User expands and collapses the recent transactions list
    Given the user has recorded more than five expenses
    When the user views the dashboard
    And the user selects "Show more"
    Then the app should reveal up to ten additional transactions
    And a "Show less" option should become available
    When the user selects "Show less"
    Then the app should show only the latest five transactions again
```
