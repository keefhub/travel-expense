# Feature 13: Reset App Data

```gherkin
Feature: Reset app data
  As a traveller
  I want to reset the app data
  So that I can clear my trip and start again

  Scenario: User chooses to reset app data
    Given the user has saved trip or expense data
    When the user selects reset app data
    Then the app should show a confirmation warning

  Scenario: User confirms reset
    Given the user is shown the reset confirmation warning
    When the user confirms the reset
    Then the app should delete all trip, expense, category, budget, and exchange rate data from local storage
    And the app should return to the travel setup screen

  Scenario: User cancels reset
    Given the user is shown the reset confirmation warning
    When the user cancels the reset
    Then the app data should remain unchanged
```
