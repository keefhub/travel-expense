# Feature 15: Mobile Responsive Navigation

```gherkin
Feature: Mobile responsive navigation
  As a traveller
  I want simple mobile navigation
  So that I can use the app easily during my trip

  Scenario: User views app on mobile
    Given the user opens the app on a mobile screen
    When the app is displayed
    Then the layout should be mobile-friendly
    And the app should show bottom navigation

  Scenario: Mobile bottom navigation is displayed
    Given the user is using the app on mobile
    When the app is displayed
    Then the bottom navigation should include Home
    And the bottom navigation should include Add Expense
    And the bottom navigation should include Categories
    And the bottom navigation should include Settings

  Scenario: User uses bottom navigation
    Given the user is viewing the app on mobile
    When the user taps a bottom navigation item
    Then the app should navigate to the selected page

  Scenario: User views app on desktop browser
    Given the user opens the app on a larger browser screen
    When the app is displayed
    Then the layout should adjust responsively
    And dashboard cards, charts, and forms should remain readable
```
