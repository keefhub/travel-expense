# Feature 4: Country and Currency Mapping

```gherkin
Feature: Country-based trip currency
  As a traveller
  I want the app to determine the trip currency from my selected country
  So that I do not need to manually choose the main trip currency

  Scenario: User selects a supported country
    Given the user is setting up or editing a trip
    When the user selects a country from the supported country list
    Then the app should automatically assign the expected trip currency

  Scenario: User searches for an unsupported country
    Given the user is setting up or editing a trip
    When the user searches for a country that is not supported
    Then the app should not allow the unsupported country to be selected
    And the app should show a message explaining that only supported countries are available

  Scenario: Supported country list is shown
    Given the user is setting up or editing a trip
    When the country field is displayed
    Then the app should show only supported countries
```
