# Feature 21: View Trip Balances

```gherkin
Feature: View trip balances
  As a participant
  I want to see the running balance across the group
  So that I know who owes whom and how much

  Scenario: I view the trip's simplified balances
    Given expenses have been recorded with payers and splits on a shared trip
    When I open the balances view
    Then I see a simplified list of who owes whom and how much

  Scenario: Balances convert multi-currency expenses to the trip currency
    Given expenses were recorded in multiple currencies, each with an exchange rate entered
    When I view balances
    Then all amounts are shown converted into the trip currency

  Scenario: Balances are simplified to the minimum number of settlements
    Given the raw expense history would otherwise show A owing B and B owing C the same amount
    When I view balances
    Then I see a single simplified line: A owes C

  Scenario: No expenses yet shows everyone settled up
    Given no expenses have been recorded on the shared trip
    When I view balances
    Then I see a message that everyone is settled up

  Scenario: A fully settled pair isn't shown as a balance line
    Given two participants' net balance with each other is exactly zero
    When I view balances
    Then no line is shown between those two participants

  Scenario: Balances are incomplete when a currency has no exchange rate
    Given an expense was recorded in a currency with no exchange rate entered
    When I view balances
    Then I see that balances are incomplete, rather than an incorrect number

  Scenario: A departed participant's balance still counts
    Given a participant who has left or been removed still has an outstanding balance
    When I view balances
    Then their balance still appears, shown under their retained name

  Scenario: Viewing balances while offline
    Given my device has no internet connection
    When I try to view balances
    Then I see a friendly message that this requires connectivity

  Scenario: Loading balances fails when the server is unreachable
    Given I open the balances view
    When the app cannot reach the server
    Then I see a friendly error message

  Scenario: Simplified balances reconcile exactly
    Given expenses whose shares don't divide evenly
    When I view the simplified balances
    Then each amount is rounded to 2 decimal places
    And the total owed across the group equals the total owing
```

## Assumptions

1. All balances are computed and displayed in the trip currency; expenses recorded in other
   currencies are converted using the exchange rates entered for the trip (feature 007), reusing
   the same conversion logic as feature 006's totals.
2. If any currency used in the trip's expenses has no exchange rate entered, balances are shown as
   incomplete rather than computed with a missing or assumed rate — mirroring `OVERVIEW.md` §3
   assumption 10's rule for remaining budget.
3. Balances are simplified: rather than showing every individual payer/split relationship, the
   view nets each pair down and reduces the group's debts to the minimum number of settlements
   needed.
4. A pair of participants whose net balance is exactly zero is omitted from the list entirely,
   rather than shown as a "$0.00" line.
5. A participant who has left or been removed (feature 019) still has their outstanding balance
   computed and shown, under their retained name.
6. This feature is read-only; no balance can be marked paid or adjusted here — that is feature 022.
7. Viewing balances requires connectivity, consistent with `OVERVIEW.md` §2's shared-trip
   connectivity requirements, since the underlying expense data lives server-side.

## Out of Scope

- Marking any balance as settled — that is feature 022.
- Editing or correcting an expense from the balances view.
- Any per-currency (non-converted) balance display.
- Notifying participants of their balance outside the app (no push/email/SMS).

## Deferred

None.
