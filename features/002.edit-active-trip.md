# Feature 2: Edit Active Trip

```gherkin
Feature: Edit active trip
  As a traveller
  I want to edit my trip details
  So that I can correct my destination, travel dates, or budget during the trip

  Scenario: User opens trip settings
    Given the user has an active trip
    When the user opens trip settings
    Then the app should display the saved destination country
    And the app should display the saved start date
    And the app should display the saved end date
    And the app should display the calculated number of travel days
    And the app should display the saved budget if one exists
    And the app should display the trip currency

  Scenario: User updates trip details
    Given the user is editing the active trip
    When the user changes the country, start date, end date, or budget
    And the user saves the changes
    Then the app should update the active trip in local storage
    And the app should recalculate the travel duration
    And the app should update the expected trip currency based on the selected country

  Scenario: User removes the optional budget
    Given the user has an active trip with a budget
    When the user removes the budget value
    And the user saves the trip details
    Then the app should save the trip without a budget
    And the dashboard should no longer show remaining budget calculations

  Scenario: User enters invalid edited trip details
    Given the user is editing the active trip
    When the user enters an invalid date range or invalid budget
    Then the app should show a validation message
    And the app should not save the changes
```
