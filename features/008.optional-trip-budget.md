# Feature 8: Optional Trip Budget

```gherkin
Feature: Optional trip budget
  As a traveller
  I want to set an optional trip budget
  So that I can compare my spending against my planned budget

  Scenario: User sets a budget during trip setup
    Given the user is creating a trip
    When the user enters a valid budget amount
    Then the budget should be saved in the trip currency
    And the dashboard should show the budget

  Scenario: User skips budget setup
    Given the user is creating a trip
    When the user does not enter a budget
    Then the app should allow the trip to be created
    And the dashboard should not show remaining budget calculations

  Scenario: User edits the trip budget
    Given the user has an active trip
    When the user updates the budget amount
    Then the updated budget should be saved in local storage
    And the dashboard should update the remaining budget

  Scenario: Dashboard shows remaining budget when conversion is complete
    Given the user has set a trip budget
    And all non-trip currencies have exchange rates
    When the user views the dashboard
    Then the app should show the total budget
    And the app should show total spending converted into the trip currency
    And the app should show the remaining budget

  Scenario: Dashboard cannot fully calculate remaining budget
    Given the user has set a trip budget
    And one or more non-trip currencies do not have exchange rates
    When the user views the dashboard
    Then the app should show the budget
    And the app should show spending grouped by original currency
    And the app should indicate that remaining budget cannot be fully calculated
```
