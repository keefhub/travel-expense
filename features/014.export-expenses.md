# Feature 14: Export Expenses

```gherkin
Feature: Export expenses
  As a traveller
  I want to export my expenses
  So that I can keep a copy outside the app

  Scenario: User exports expenses
    Given the user has recorded expenses
    When the user selects export expenses
    Then the app should generate a CSV export of the expense data
    And the export should include date, category, currency, amount, payment method, location, and description if available

  Scenario: User exports with no expenses
    Given the user has no recorded expenses
    When the user selects export expenses
    Then the app should show a message that there are no expenses to export
```
