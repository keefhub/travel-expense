# Feature 11: Unsaved Expense Warning

```gherkin
Feature: Unsaved expense warning
  As a traveller
  I want to be warned before losing unsaved expense input
  So that I do not accidentally discard my entries

  Scenario: User refreshes record expense page with empty form
    Given the user is on the record expense page
    And the expense form is empty
    When the user refreshes the browser
    Then the app should allow the refresh without warning

  Scenario: User refreshes record expense page with unsaved input
    Given the user is on the record expense page
    And the user has entered unsaved expense details
    When the user attempts to refresh the browser
    Then the browser should show a standard refresh warning
    And the warning should indicate that unsaved changes may be lost

  Scenario: User confirms refresh
    Given the user is shown the browser refresh warning
    When the user confirms the refresh
    Then the page should refresh
    And the unsaved input should be discarded

  Scenario: User cancels refresh
    Given the user is shown the browser refresh warning
    When the user cancels the refresh
    Then the page should not refresh
    And the unsaved input should remain visible

  Scenario: User navigates away with unsaved input
    Given the user is on the record expense page
    And the user has entered unsaved expense details
    When the user attempts to navigate away
    Then the app should warn the user that unsaved input will be discarded

  Scenario: User confirms navigation away
    Given the user is shown an unsaved changes warning
    When the user confirms navigation
    Then the app should navigate away from the record expense page
    And the unsaved input should be discarded

  Scenario: User cancels navigation away
    Given the user is shown an unsaved changes warning
    When the user cancels navigation
    Then the user should remain on the record expense page
    And the unsaved input should remain visible
```
