# Feature 6: Multi-Currency Expense Tracking

```gherkin
Feature: Multi-currency expense tracking
  As a traveller
  I want to record expenses in different currencies
  So that I can track actual spending across my trip

  Scenario: User records an expense in the trip currency
    Given the trip currency is SGD
    When the user records an expense in SGD
    Then the expense should be saved as an SGD expense
    And no exchange rate should be required

  Scenario: User records an expense in a different currency
    Given the trip currency is SGD
    When the user records an expense in JPY
    Then the app should allow the JPY expense to be saved
    And the expense should retain its original currency and amount

  Scenario: Dashboard shows totals by original currency
    Given the user has recorded expenses in more than one currency
    When the user views the dashboard
    Then the app should show total spending grouped by currency
    And the totals should be displayed using currency codes

  Scenario: User enters a fixed exchange rate
    Given the user has recorded expenses in a currency different from the trip currency
    When the user enters a fixed exchange rate for that currency
    Then the app should calculate the converted amount in the trip currency
    And the converted total should be shown on the dashboard

  Scenario: Exchange rate is not provided
    Given the user has recorded expenses in more than one currency
    And no exchange rate has been provided for one or more currencies
    When the user views the dashboard
    Then the app should still show totals by original currency
    And the app should indicate that converted totals are incomplete
```
